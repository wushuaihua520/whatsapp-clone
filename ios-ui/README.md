# WhatsApp iOS UI

An independent Flutter copy of the showcase app, redesigned around WhatsApp's
current iOS 26 visual language.

Highlights:

- floating five-tab navigation with a translucent Liquid Glass treatment
- iOS-style large titles, actions, grouped settings, and navigation motion
- translucent conversation header and floating message composer
- copied dummy data, routes, media assets, and messaging interactions

Run it independently from the repository root:

```bash
cd ios-ui
flutter pub get
flutter run
```
